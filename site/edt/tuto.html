Écran Emplois du temps — mode d'emploi

Voir les emplois du temps d'une équipe, choisir le cours à visiter, l'entretien et une réunion d'équipe, puis prévenir l'établissement.

Choisir l'établissement et les professeur·es

  • Établissement : recherche sur le nom, la ville ou l'UAI ; les petites cases 18, 28, 36, 37, 41, 45 filtrent par département.
  • Professeur·e : recherche dans tous les établissements ; ＋ Toute l'équipe affiche l'équipe entière.
  • Pastilles : (S) AGREG int. · PU · 100 % pour un·e stagiaire de la liste Suivi PSTG (corps, concours, public / privé, quotité), MD pour un·e maître·sse délégué·e suivi·e. Filtres « Stagiaires » et « MD » en tête de la liste.
  • Depuis le Plan d'inspection, le bouton Emploi du temps d'une visite ouvre directement l'établissement et le ou la professeur·e ; la visite du plan est rappelée en haut.

Lire la semaine

  • Date : semaine réelle (A, B ou vacances, d'après la table Calendrier) ; Sem. A, Sem. B, Semaine type : semaines théoriques.
  • Cours hachurés : quinzaine (Q1 = semaine A, Q2 = semaine B — à vérifier auprès de l'établissement) ou semestre ; en pointillés : cours dans un autre établissement.
  • Cliquer sur l'en-tête d'un jour pour ne voir que ce jour (une colonne par professeur·e).
  • Créneaux visite + entretien : ★ sur les cours suivis d'une heure libre, proposée en vert pour l'entretien.

Préparer la visite

  1. Cliquer sur un cours → Visiter ce cours (1re heure, 2e heure ou tout le cours, pour un cours long).
  2. Valider l'entretien (créneau vert, horaire réglable).
  3. ＋ Réunion d'équipe : placée à l'heure où le plus de professeur·es de l'équipe n'ont pas cours ; le planning indique combien sont libres.
  4. Le planning proposé signale chevauchements, vacances, cours de quinzaine absents à la date choisie.

Prévenir par mail

  • Un bouton par modèle de votre rôle : par exemple Proposer une visite (au chef d'établissement) et Annoncer la visite (à l'équipe, copie au chef). La messagerie s'ouvre avec le texte prêt ; rien n'est envoyé par l'application. Le tableau du planning est aussi copié : le coller dans le mail (Ctrl+V).
  • Les modèles se modifient dans Modèles & phrases → Mails (IA-IPR) : destinataires, copie, objet, texte, avec {etablissement}, {date}, {planning}, {planning_profs} (une ligne par professeur·e : visite, entretien), {visite}, {entretien}, {professeurs}, {signataire}, {fonction}, {ipr}.

Mémoriser, caler

  • 💾 Mémoriser le planning : enregistré comme « Planning proposé » ; Charger le restaure.
  • ✅ Visite calée : enregistré comme « Visite calée », et la date est reportée dans le plan d'inspection pour les professeur·es du planning qui y ont une visite cette année.
  • Chaque CMi enregistre et supprime ses propres plannings ; les IA-IPR, tous.

Verser les emplois du temps (IA-IPR)

  1. Sur Siiprien : page de l'établissement → Emploi du temps → Tous.
  2. Ctrl+A, Ctrl+C, puis ＋ Ajouter les EdT d'un établissement et Ctrl+V. L'UAI est lu sur la ligne « Rne » ; les créneaux déjà présents pour cet établissement sont remplacés (ou gardés, au choix).
  3. Pour verser d'un coup la table d'EdT-widget : importer un fichier (export CSV de cette table), ou copier la table dans Grist (en-têtes compris) et la coller dans la fenêtre.
  4. Noms chiffrés (« v1:… », table venant d'une autre application qui chiffre les noms) : la fenêtre demande la clé de l'autre document. Dans l'autre document, ouvrir Données brutes → Chiffrement, copier la ligne avec ses en-têtes (Sel, Iterations, Version, Verificateur) et la coller ; saisir la phrase de passe de l'autre application et l'identifiant de la table copiée (souvent EDT), puis Déchiffrer. Tout se fait dans le navigateur : rien n'est envoyé, la phrase n'est pas gardée. Les noms sont ensuite enregistrés ici chiffrés avec la phrase de cette application.
  5. Les noms des professeur·es sont chiffrés dans les emplois du temps : sans « Révéler » (menu de l'application), l'écran est masqué et rien ne peut être ajouté ni mémorisé.

Le calendrier (semaines A / B, vacances) se remplit dans la table Calendrier (une ligne par semaine).
