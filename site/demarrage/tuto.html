Premier démarrage — mode d'emploi

L'assistant s'ouvre tout seul la première fois que la personne qui a importé le modèle ouvre la page App. Il met l'application à votre nom et à celui de votre académie. Chaque étape peut être passée.

Les étapes

  1. Votre compte : prénom, nom et adresse de votre compte Grist (avatar, en haut à droite de Grist). Ils remplacent le compte d'exemple « Benny B ». L'assistant vérifie aussitôt que l'adresse est bien celle du compte connecté.
  2. Académie : son nom et le domaine des adresses (ce.<UAI>@…). Logo d'Orléans-Tours intégré ; pour une autre académie, le déposer ensuite dans Administration → Académie (facultatif).
  3. Discipline : imprimée dans les rapports (tableau d'identification, en-tête, bas de page). Hors mathématiques, les phrases types d'exemple peuvent être retirées.
  4. Établissements : collèges, lycées, lycées professionnels et EREA, publics et privés, de l'académie, téléchargés depuis l'open data du ministère (data.education.gouv.fr, Licence Ouverte), avec adresse, position, e-mail et téléphone. Les natures se cochent ou se décochent avant l'ajout.
  5. Données d'exemple : à garder pour essayer, ou à supprimer avant de travailler pour de vrai. Seules les données inventées sont visées (adresses en .example) ; modèles de rapport, rubriques et phrases validées restent.
  6. Phrase de chiffrement : se choisit dans Administration → Chiffrement. Phrase perdue = données perdues.
  7. Professeur·es : fichier Siiprien versé dans Administration → Import (jamais l'import de Grist).
  8. Collègues : partage du document dans Grist, puis Annuaire → « Donner accès à l'application ».

Plus tard

« Terminer l'installation » retire l'assistant du menu. Pour le rouvrir (par exemple pour supprimer les données d'exemple) : Administration → Premier démarrage → « Rouvrir l'assistant ».
